# NOVA — Local Socket Chat

แอปแชทหลายคนผ่าน **TCP socket** ในเครือข่าย LAN เขียนด้วย Python + CustomTkinter
ไม่ใช้ฐานข้อมูลและไม่ต้องใช้อินเทอร์เน็ต

## สิ่งที่ต้องมี
- Windows (แนะนำ) และ **Python 3.8 ขึ้นไป** (ติ๊ก *Add Python to PATH* ตอนติดตั้ง)
- ทุกเครื่องที่จะแชทต้องอยู่ใน Wi-Fi/LAN เดียวกัน

## เริ่มใช้งานเร็วที่สุด
1. ดับเบิลคลิก **`start.bat`** (ครั้งแรกจะติดตั้ง CustomTkinter ให้อัตโนมัติ)
2. กรอกชื่อในช่อง **Display name**
3. กด **Host a local room** เพื่อเปิดเซิร์ฟเวอร์และเข้าห้องทันที

## ให้เพื่อนเข้าห้องจากเครื่องอื่น
**ฝั่งผู้โฮสต์**
1. ดู **LAN IP** ที่มุมขวาบนของหน้าต่างแชท
2. กด **Copy** เพื่อคัดลอก `IP:PORT` (เช่น `192.168.1.25:5050`) ส่งให้เพื่อน
3. ถ้าเพื่อนเข้าไม่ได้ ให้อนุญาต **TCP พอร์ต 5050** ใน Windows Firewall

**ฝั่งเพื่อน**
1. เปิด `start.bat`
2. ใส่ชื่อ แล้วแก้ช่อง Host เป็น IP ของผู้โฮสต์ (พอร์ตเริ่มต้น `5050`)
3. กด **Connect to room**

> เปิดหน้าต่างแชทหลายอันบนเครื่องเดียวกันเพื่อทดสอบได้ โดยใช้ `127.0.0.1`

## ปุ่มและฟังก์ชัน
| ปุ่ม | ทำอะไร |
|---|---|
| **Host a local room** | เปิด `server.py` เบื้องหลังแล้วเชื่อมต่อให้เอง ปิดแอปเมื่อไหร่เซิร์ฟเวอร์ปิดด้วย |
| **Connect to room** | เชื่อมต่อไปยัง Host:Port ที่กรอก (กดอีกครั้งเพื่อ **Disconnect**) |
| **Copy** | คัดลอก `IP:PORT` ของเครื่องนี้ |
| **↻** | ตรวจ LAN IP ใหม่ (โปรแกรมตรวจเองทุก 15 วินาที) |
| **Send →** / Enter | ส่งข้อความ |

- ชื่อซ้ำจะถูกต่อท้ายอัตโนมัติ เช่น `Alice (2)`
- รายชื่อคนออนไลน์แสดงที่ sidebar ด้านซ้าย
- เปลี่ยนชื่อไม่ได้ขณะเชื่อมต่อ ต้อง Disconnect ก่อน

## รันแยกด้วยคำสั่ง
```bash
python -m pip install -r requirements.txt
python server.py 5050     # เปิดเซิร์ฟเวอร์ (ไม่ใส่พอร์ต = 5050)
python app.py             # เปิดหน้าต่างแชท
```
ใช้วิธีนี้เมื่ออยากรันเซิร์ฟเวอร์ค้างไว้โดยไม่ต้องเปิดหน้าต่างแชท

## โครงสร้างโปรเจกต์
| ไฟล์ | หน้าที่ |
|---|---|
| `server.py` | TCP server รับหลาย client และกระจายข้อความ (1 thread ต่อ client) |
| `app.py` | UI แบบ CustomTkinter: bubble แชท, รายชื่อออนไลน์, แสดง/คัดลอก IP |
| `start.bat` | ติดตั้ง dependency ถ้ายังไม่มี แล้วเปิดแอป |
| `requirements.txt` | `customtkinter>=5.2,<6` |

## รายละเอียดทางเทคนิค
- โปรโตคอล: JSON 1 บรรทัดต่อข้อความ (UTF-8) ชนิดข้อความ: `join`, `welcome`, `chat`, `system`, `users`
- ข้อความยาวสุด 1,200 ตัวอักษร ชื่อยาวสุด 24 ตัวอักษร
- บรรทัดที่ยาวเกิน 12,000 ไบต์จะถูกตัดการเชื่อมต่อ
- เซิร์ฟเวอร์เก็บประวัติ **60 ข้อความล่าสุดในหน่วยความจำ** ปิดเซิร์ฟเวอร์แล้วประวัติหาย

## แก้ปัญหาเบื้องต้น
| อาการ | วิธีแก้ |
|---|---|
| `Connection failed` | ตรวจ IP/พอร์ต, เซิร์ฟเวอร์เปิดอยู่ไหม, Firewall อนุญาต TCP 5050 หรือยัง |
| `Could not start server` | พอร์ตอาจถูกใช้อยู่ ลองเปลี่ยนเลขพอร์ตในช่อง Port |
| LAN IP แสดง `Unavailable` | ยังไม่ได้เชื่อมต่อ Wi-Fi/LAN ลองกด ↻ หลังต่อเน็ตแล้ว |
| `start.bat` ไม่ทำงาน | ตรวจว่าเปิด `python --version` ใน Command Prompt ได้ |

## ข้อควรระวังด้านความปลอดภัย
ใช้ในเครือข่ายภายในที่เชื่อถือได้เท่านั้น ไม่มีบัญชีผู้ใช้ ไม่มีการยืนยันตัวตน และ**ไม่มีการเข้ารหัส**
ข้อความเป็น plaintext ใครในเครือข่ายเดียวกันที่รู้ IP:พอร์ตก็เข้าห้องและดักข้อมูลได้ อย่าใช้ส่งข้อมูลสำคัญ
