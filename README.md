# NOVA — Python Local Socket Chat

แอปแชทด้วย **CustomTkinter + TCP Socket** ไม่มีฐานข้อมูลและไม่ต้องใช้อินเทอร์เน็ต

## เริ่มใช้งาน
1. ดับเบิลคลิก **start.bat** (ติดตั้ง CustomTkinter ให้อัตโนมัติครั้งแรก)
2. กรอกชื่อ แล้วคลิก **Host a local room** เพื่อเปิดเซิร์ฟเวอร์และเข้าห้อง
3. เปิด **start.bat** อีกครั้ง เพื่อเปิดหน้าต่างแชทที่สอง แล้วกด **Connect to room**
4. หากเชื่อมต่อจากคอมเครื่องอื่นใน Wi-Fi/LAN เดียวกัน ให้ใส่ **IPv4 ของเครื่องโฮสต์** แทน 127.0.0.1 และใช้พอร์ต 5050

## คำสั่งแยก
python -m pip install -r requirements.txt
python server.py 5050
python app.py

- server.py: TCP server รับผู้ใช้หลายคนและกระจายข้อความ
- app.py: UI CustomTkinter, รายชื่อออนไลน์, ข้อความแบบ bubble, เวลา และการเชื่อมต่อ
- ส่งข้อมูลผ่าน JSON 1 บรรทัดต่อข้อความ (UTF-8)
- เก็บข้อความล่าสุด **60 ข้อความในหน่วยความจำ** เท่านั้น; ปิดเซิร์ฟเวอร์แล้วประวัติหาย

สำหรับเครือข่ายภายในที่เชื่อถือได้เท่านั้น: ไม่มีบัญชีผู้ใช้/การเข้ารหัส/การยืนยันตัวตน และ Firewall อาจต้องอนุญาต TCP 5050 เพื่อให้เพื่อนร่วม LAN เข้าถึงได้

## แชร์ IP ให้เพื่อน
- IP หลักจะแสดงด้านขวาบนของหน้าต่างแชทโดยอัตโนมัติ
- คลิก **Copy** เพื่อคัดลอกที่อยู่ `IP:PORT` หรือ **↻** เพื่อตรวจสอบใหม่
- โปรแกรมตรวจสอบการเปลี่ยน IP ทุก 15 วินาทีโดยไม่ใช้อินเทอร์เน็ต
- เพื่อนใช้เลข IP และ Port นี้กรอกในช่อง Connection ของแอปอีกเครื่อง
